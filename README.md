# SQL Security Analysis

A database-learning project demonstrating SQL querying, data analysis and basic defensive database-security concepts.

## Objectives
- Create a small relational dataset.
- Query records using SQL.
- Use joins and aggregation.
- Identify suspicious access patterns.
- Discuss SQL injection prevention.

## Security Concepts
### Parameterised Queries
Applications should use parameterised queries rather than constructing SQL through string concatenation.

### Least Privilege
Database accounts should have only the permissions required for their role.

### Logging
Authentication and sensitive database operations should be monitored.

## Skills
SQL, relational databases, data analysis and application-security fundamentals.
